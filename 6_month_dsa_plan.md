# 6-Month DSA Plan for Placements (Python)

As a 3rd-year student, this 6-month window is critical for placement preparation. The goal is to move from basics to advanced patterns, allowing you to confidently tackle coding rounds and technical interviews.

## Month 1: Python Basics & Foundational Concepts
**Goal**: Master Python syntax and the core concepts of algorithm analysis.

*   **Week 1**: Python Syntax, Variables, Loops, Conditionals, Functions. (Solve 10-15 very basic string/math problems).
*   **Week 2**: Lists (Arrays), Tuples, Dictionaries (Hash Maps), Sets. Learn list comprehensions.
*   **Week 3**: **Time & Space Complexity (Big O Notation)**. You *must* understand this before moving forward. Learn how to calculate the efficiency of your loops.
*   **Week 4**: Basic Math & Bit Manipulation (Modulo arithmetic, prime numbers, bitwise AND/OR/XOR).

## Month 2: Arrays, Strings, and Hashing
**Goal**: Master the most frequently asked basic data structures.

*   **Week 1-2**: **Arrays & Strings**.
    *   *Patterns*: Iteration, Reverse, Prefix Sum.
    *   *Problems*: Two Sum, Best Time to Buy and Sell Stock, Contains Duplicate.
*   **Week 3**: **Hash Maps & Hash Sets**.
    *   *Focus*: Using dictionaries to cache data for $O(1)$ lookups.
    *   *Problems*: Valid Anagram, Group Anagrams.
*   **Week 4**: **Two Pointers**.
    *   *Focus*: Iterating with two pointers from opposite ends or same end.
    *   *Problems*: Valid Palindrome, 3Sum, Container With Most Water.

## Month 3: Linked Lists, Stacks, & Queues
**Goal**: Understand pointer manipulation and sequence tracking.

*   **Week 1-2**: **Linked Lists**.
    *   *Focus*: Singly and Doubly Linked Lists, traversing, reversing, finding cycles.
    *   *Problems*: Reverse Linked List, Merge Two Sorted Lists, Linked List Cycle.
*   **Week 3**: **Stacks**.
    *   *Focus*: LIFO (Last-In-First-Out) concepts.
    *   *Problems*: Valid Parentheses, Evaluate Reverse Polish Notation, Min Stack.
*   **Week 4**: **Queues**.
    *   *Focus*: FIFO (First-In-First-Out) concepts. (Use `collections.deque` in Python).

## Month 4: Trees, Searching, & Sorting
**Goal**: Master hierarchical data and efficient searching.

*   **Week 1**: **Binary Search**.
    *   *Focus*: $O(\log n)$ search on sorted arrays.
    *   *Problems*: Binary Search, Search a 2D Matrix, Find Minimum in Rotated Sorted Array.
*   **Week 2**: **Sorting Algorithms**.
    *   *Focus*: Understand Merge Sort and Quick Sort conceptually.
*   **Week 3-4**: **Binary Trees & Binary Search Trees (BST)**.
    *   *Focus*: Traversals (Inorder, Preorder, Postorder, Level-order/BFS). Recursion is heavily used here.
    *   *Problems*: Maximum Depth of Binary Tree, Invert Binary Tree, Lowest Common Ancestor.

## Month 5: Advanced Data Structures
**Goal**: Tackle complex interview topics.

*   **Week 1-2**: **Graphs**.
    *   *Focus*: Representing graphs (Adjacency List). Traversals: BFS (using Queues) and DFS (using Recursion/Stacks).
    *   *Problems*: Number of Islands, Clone Graph, Course Schedule.
*   **Week 3**: **Heaps (Priority Queues)**.
    *   *Focus*: Finding the Top K elements, Min-Heap vs Max-Heap (Use `heapq` module in Python).
    *   *Problems*: Kth Largest Element in an Array, Top K Frequent Elements.
*   **Week 4**: **Tries (Prefix Trees)**.
    *   *Focus*: Fast string searching and autocomplete features.
    *   *Problems*: Implement Trie.

## Month 6: Advanced Algorithms & Interview Prep
**Goal**: Master optimization patterns and practice under pressure.

*   **Week 1**: **Sliding Window**.
    *   *Focus*: Optimizing nested loops for contiguous sub-arrays/strings.
    *   *Problems*: Longest Substring Without Repeating Characters, Minimum Window Substring.
*   **Week 2**: **Backtracking**.
    *   *Focus*: Exploring all combinations/permutations.
    *   *Problems*: Subsets, Permutations, Combination Sum.
*   **Week 3**: **Dynamic Programming (1D & 2D)**.
    *   *Focus*: Caching overlapping subproblems (Memoization) and bottom-up tabulation.
    *   *Problems*: Climbing Stairs, Coin Change, Longest Common Subsequence.
*   **Week 4**: **Mock Interviews & Timed Contests**.
    *   *Action*: Do LeetCode daily challenges, participate in weekly contests, and do mock interviews with peers.

## Daily Routine Advice
1.  **Consistency**: 1-2 hours every day is far better than 10 hours on Sunday.
2.  **The 45-Minute Rule**: If you are stuck for 45 minutes, read the solution. Understand the underlying logic, close the tab, and write it yourself.
3.  **Keep a Log**: Note down patterns you learn (e.g., "If I need to find top K elements, I should use a Heap").
